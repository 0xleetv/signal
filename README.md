# SIGNAL

A scroll-driven anti-gravity transaction story across five acts, built with vanilla HTML, CSS, and JavaScript.

## Concept
As the page scrolls, a single point of light travels through five distinct acts:
- **Act I: Wallet** — The point is born and a balance tilts.
- **Act II: Handoff** — The point leaves the wallet into the propagation pipe.
- **Act III: The Chain** — The point materializes as a block joining a growing tower.
- **Act IV: Confirmation** — Cryptographic consensus checkmarks ripple outward.
- **Act V: Settled** — The piece breathes once as the final settlement headline lands.

Scrolling in reverse runs the entire transaction sequence backward.

## Tech Stack
- Vanilla HTML5, CSS3, and ES6+ JavaScript.
- HTML5 Canvas with hardware-accelerated 2D rendering (pixel ratio capped at 2 for mobile fluidity).
- Zero frameworks, zero dependencies, zero build step.
- Google Font: `Space Grotesk`.
- Full `prefers-reduced-motion` accessibility support.
